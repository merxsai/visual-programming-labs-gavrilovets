\## 2. Краткое описание выполненных задач (Потоки)



1\. \*\*2.1 Inject ➔ Debug:\*\* Настроен периодический запуск каждые 5 секунд с передачей фамилии `Гавриловец` и топика `lab2/gavrilovets/basic`. Вывод полного объекта сообщения.

2\. \*\*2.2 Function node:\*\* Реализована JS-функция с использованием `let/const`, циклом `for`, условием `if/else`, массивом и возвратом результирующего объекта.

3\. \*\*2.3 Switch node:\*\* Реализовано ветвление потока по значению `msg.payload` (ветка 1: `<= 50`, ветка 2: `> 50`).

4\. \*\*2.4 Change / Set node:\*\* Заданы 3 правила модификации сообщения: установка топика, времени `timestamp` и полезной нагрузки `payload`.

5\. \*\*2.5 Template node:\*\* Сгенерирован Mustache-шаблон для форматирования текста из входящего JSON-объекта студента.

6\. \*\*2.6 HTTP Request:\*\* Выполнен GET-запрос к внешнему публичному API (`api.chucknorris.io`) с парсингом JSON-ответа.

7\. \*\*2.7 MQTT:\*\* Реализована публикация и подписка на топик `student/gavrilovets/lab2/test` через публичный брокер `broker.hivemq.com:1883`.

8\. \*\*2.8 GET-эндпоинты:\*\* Создан REST API сервис с 3 эндпоинтами (`/api/text`, `/api/info`, `/api/items?id=`) с обработкой кодов 200, 400 и 404. Подробная документация оформлена в \[api.md](api.md).

9\. \*\*2.9 Dashboard:\*\* Установлена библиотека `node-red-dashboard`, настроен UI со спидометром (Gauge) и графиком в реальном времени (Chart).

10\. \*\*2.10 Telegram-бот:\*\* Подключен бот `tvl\_lab2\_gavrilovets\_bot`, настроена обработка команд `/start`, `/info` и Echo-ответ на входящие сообщения.

11\. \*\*2.11 Чтение и запись файлов:\*\* Реализовано сохранение JSON-данных на диск контейнера (`/data/student.json`) и чтение содержимого.

12\. \*\*2.12 Контекст (flow context):\*\* Реализован счетчик нажатий, сохраняющий состояние между вызовами в памяти `flow context` с помощью `flow.get()` и `flow.set()`.
