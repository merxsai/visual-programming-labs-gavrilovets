## Исходный шаблон

За основу выбран [FAQ Chatbot Template](https://typebot.com/templates/faq). Его сценарий начинается с приветствия, предлагает несколько тем и умеет возвращать пользователя в меню. Пункт «Другой вопрос» принимает свободный текст и завершает диалог. В учебной версии меню помогает найти материалы по курсу и подготовиться к защите работ по Bubble и n8n.

Исходный JSON взят из [каталога шаблонов Typebot](https://github.com/baptisteArno/typebot.io/blob/main/packages/templates/src/typebots/faq.json). В адаптации сохранены ID групп, переходы по кнопкам и возвраты через Jump. Это позволяет сравнить сценарии до и после изменений.

## Изменения

- Переведены приветствие, темы меню, кнопки, подсказка формы вопроса и системные сообщения об ошибках.
- Добавлены подсказка о навигации и сообщение с повтором вопроса. Text Input сохраняет введённый текст в переменной `Вопрос`.
- В ветке «Узнать версию n8n» блок Set variable сбрасывает `Версия n8n` перед каждым запросом. HTTP Request выполняет GET к публичному API GitHub. Значение `data.tag_name` записывается в `Версия n8n`.
- Condition проверяет, начинается ли значение с `n8n@`. Успешная ветка показывает версию. Ветка Else объясняет, что делать при недоступности GitHub. Обе ветки возвращают пользователя в меню через Jump.
- Изменены фон чата, цвета реплик и кнопок. Кнопки меню расположены вертикально. Предпросмотр страницы использует русские заголовок и описание.

## Примеры запросов к ИИ

> Адаптируй FAQ Typebot под справочник по технологиям визуального программирования. Переведи весь видимый текст и сохрани переходы исходного шаблона.

> Добавь к вопросу переменную и покажи её значение в конце диалога. Добавь короткую подсказку о возврате в меню.

> Настрой HTTP Request к публичному GitHub API, сохрани поле tag_name и добавь условие для успешного ответа и запасной ветки.

> Предложи палитру для светлого чата и контрастных кнопок, которые читаются на мобильном экране.

## Вывод

У FAQ удобно менять тему по группам и сохранять проверенную структуру переходов. Основную и запасную ветки можно отличить по результату одного условия. Для данных из API нужна отдельная переменная, иначе повторный запрос может показать предыдущее значение.
